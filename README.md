# Laravel + React con Inertia.js

Una aplicación web moderna construida con **Laravel 12**, **React 19**, **Inertia.js** y **Tailwind CSS**. Incluye autenticación con Fortify/Jetstream, gestión de productos y un sistema robusto de pruebas.

## ✨ Características

- ✅ **Frontend Moderno**: React 19 con Inertia.js para aplicaciones reactivas sin necesidad de APIs REST
- 🔐 **Autenticación Completa**: Laravel Fortify + Jetstream con soporte para dos factores
- 🎨 **Diseño Responsivo**: Tailwind CSS v4 + Radix UI para componentes accesibles
- 📦 **Gestión de Productos**: CRUD completo con imágenes y validaciones
- 🧪 **Testing**: Pest + PHPUnit para pruebas robustas
- 🚀 **DevX**: Hot reload con Vite, type-safe con TypeScript
- 🐘 **PHP 8.2+**: Código moderno y eficiente
- 🐳 **Docker**: Configuración incluida para desarrollo local

## 📋 Requisitos

- **PHP** 8.2 o superior
- **Composer** (gestor de dependencias de PHP)
- **Node.js** 18+ y **npm**
- **SQLite** o **MySQL** (SQLite viene configurado por defecto)
- **Git**
- **(Opcional) Docker & Docker Compose**
